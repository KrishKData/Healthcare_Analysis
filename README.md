# Healthcare_Analysis

Healthcare Analytics is a data analytics project focused on analyzing healthcare data to understand patient demographics, diseases, medical conditions, treatments, and healthcare outcomes.

**MS Excel** is used for data organization, cleaning, and analysis, while **Power BI** is used to create an interactive dashboard for visualizing healthcare metrics and trends.

The analysis provides insights into **patient distribution, disease patterns, treatment outcomes, lab results, and demographic trends**.

The goal of this project is to transform healthcare data into meaningful insights that can support **data-driven decision-making and better understanding of healthcare trends**.
